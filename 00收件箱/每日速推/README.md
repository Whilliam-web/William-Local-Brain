# 每日速推

这个文件夹由 Hermes 智能体每日自动维护，存放当天联网搜索整理的信息摘要。

## 工作机制

1. 智能体扫描 `01三两的打工tasks/`（推进中项目）和 `02暗恋对象/`（长期兴趣领域），推断当前关注方向。
2. 基于关注方向主动联网搜索最新公开信息。
3. 整理成结构化 Markdown 放入本文件夹，文件名格式：`YYYY-MM-DD_每日信息速推.md`。
4. 内容为**待审状态**，Whilliam 自行判断哪些内容值得沉淀进知识库其余目录。

## 文件命名规则

```
YYYY-MM-DD_每日信息速推.md
```

## 内容结构（每篇）

每篇速推包含：

- 日期与关注领域
- 每个关注领域下的信息条目（标题、摘要、来源链接、与现有知识库的关联）
- 待审标记（Whilliam 需判断是否沉淀）

## 与知识库其余目录的关系

- 内容经过 Whilliam 审阅后，可流向：
  - `01三两的打工tasks/` 对应项目的 `搜集信息/`
  - `03百宝箱/` 可复用知识
  - `05心法/` 判断与反思
  - `04深埋于地的宝藏/` 归档
- 未被采用的内容可定期清理。
