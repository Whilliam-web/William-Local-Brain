# Delta X 迭代未来官网设计说明

- 文档版本：V1.0
- 日期：2026-07-13
- 状态：设计方案已确认，待用户审阅书面稿
- 项目：Delta X 迭代未来品牌官网

## 1. 项目概述

Delta X 迭代未来是一家由浙大学生自主发起、关注中国年轻人原生创新和 PMF 商业闭环的早期孵化器，聚焦 AI 应用落地。作为浙大 X-Lab 创投生态向市场侧延伸的重要实践场景，Delta X 为学生和年轻创业者提供资本与产业命题、技术基建、团队招募、活动链接等支持，帮助项目在真实市场中快速验证并持续迭代。

官网的首要任务不是解释机构规模或罗列服务，而是让访客理解并认同 Delta X 的价值理念。第二任务是呈现近期真实活动和持续发生的创造过程。第三任务是将认同转化为加入创业者社群、报名活动或发起合作。

## 2. 品牌核心

### 2.1 核心主张

> 不用一次改变世界。
>
> 一次次，把自己的未来迭代出来。

辅助说明：

> Delta X 为中国大学生补齐创业要素，让想法进入真实市场，让每一次 Build 都成为下一次出发。

### 2.2 品牌角色

Delta X 不是高高在上的成功企业家或投资机构，而是一位“领先你两年”的 AI 创业学长或学姐：

- 自己仍在持续 Build，但已经做出过一些成果；
- 懂年轻创业者刚开始时的困难，不用成功学说教；
- 愿意分享方法、陪伴试错、介绍资源和连接伙伴；
- 有判断、有行动力、有专业度，同时保持真诚和开放；
- 相信成长发生在一次次真实实验中，而不是一次宏大的承诺里。

- 立足中国

- 中国新青年
- 创造者文化
- 创新实验
- 社群组建
- 创业精神

## 3. 目标受众与行动优先级

### 3.1 核心受众

1. 已经拥有 AI 项目的大学生创业者；
2. 正在寻找问题、伙伴或方向的青年创新者；
3. 潜在投资人；
4. 产业、高校及其他生态合作伙伴。

### 3.2 用户完成路径

网站应推动以下递进关系：

1. 理解并认同 Delta X 的价值理念；
2. 看见 Delta X 最近真实发生的活动、项目与人物；
3. 感到“这里有和我一样的人，也有人愿意搭把手”；
4. 加入创业者社群、报名活动或发起合作。

主要行动入口按顺序排列为：

1. 查看我们正在做什么；
2. 加入创业者社群；
3. 报名近期活动；
4. 成为合作伙伴。

## 4. 创意方向

### 4.1 核心概念：正在迭代的实验日志

官网是一份持续更新的 Delta X 创业实验日志，而不是一份已经写完的机构宣传册。页面通过版本号、运行状态、手写批注、真实人物、活动照片、项目片段和实验档案，让访客感受到“事情正在发生”。

整体方案以“实验日志”为主，吸收两类辅助表达：

- 通过真实人物与活动内容建立社群信任和活人感；
- 通过少量工作台、运行日志和状态反馈强化 AI 创造者与 Build 气质。

### 4.2 与参考网站的关系

参考 Spark Lab 官网的大字号宣言、克制留白、暖色强调与叙事型长页面，但不复制其品牌图形、文案或精英先锋语气。Delta X 的转译重点是中国高校青年、共同成长、实验现场和学长学姐式陪伴。

参考地址：https://www.sparklab.city/

## 5. 信息架构与页面叙事

首期采用单页长滚动官网，保证访客可以连续完成“价值共鸣—理解方法—看见行动—加入”的过程。顶部导航提供锚点跳转，移动端保持简洁。

### 5.1 顶部导航

- 品牌标识：Delta X 迭代未来
- 导航项：理念 / 迭代框架 / 最近发生 / 创造者 / 加入
- 主按钮：加入下一次迭代
- 页面状态：`DX.LOG / LIVE`

### 5.2 首屏 Hero

核心内容：

> 不用一次改变世界。
>
> 一次次，把自己的未来迭代出来。

辅助内容：

> Delta X 为中国大学生补齐创业要素，让想法进入真实市场，让每一次 Build 都成为下一次出发。

首要按钮：`查看我们正在做什么`

次要按钮：`加入创业者社群`

首屏视觉采用一张真实的青年创造或活动现场照片，叠加实验编号、日期、手绘圈画和运行状态。不得使用常见的 AI 机器人、宇宙、商务握手或成功人士素材。

### 5.3 价值宣言：为什么是 Delta X

先指出问题，再给出立场：年轻人通常不缺想法，而是缺少把想法带入真实市场的创业要素。Delta X 帮助他们获得资本和产业命题、技术基建、团队伙伴、活动与生态连接。

本区采用大字宣言与短段落交替：

- 不要求你一次性改变世界；
- 先做出第一个能被真实用户使用的版本；
- 从作品走向产品，从可能性走向可持续；
- 每次验证，都让下一步更清楚；
- 人不是被“孵化”出来的，而是在行动中把未来迭代出来。

### 5.4 迭代框架：从想法到真实市场

以横向或纵向实验循环呈现：

`发现问题 → 快速 Build → 用户验证 → 找到 PMF → 再次迭代`

每一步绑定 Delta X 的支持：

| 阶段 | 创业者正在做什么 | Delta X 提供什么 |
| --- | --- | --- |
| 发现问题 | 从真实场景识别值得解决的问题 | 产业命题、用户与场景连接 |
| 快速 Build | 把想法变成可使用的最小版本 | AI 技术基建、工具与方法 |
| 用户验证 | 让产品进入真实使用环境 | 活动、社群、用户测试机会 |
| 找到 PMF | 判断谁真正需要、为什么付费 | 商业闭环讨论、资本与行业反馈 |
| 再次迭代 | 根据证据调整产品和团队 | 团队招募、伙伴连接与持续陪跑 |

### 5.5 最近正在发生

活动卡片按三种状态呈现：

- `RECRUITING / 正在招募`
- `UPCOMING / 即将开始`
- `ARCHIVED / 实验归档`

每张卡片包含活动名称、日期、地点、简短说明、真实照片或视觉物料，以及明确行动入口。活动语言采用“最近我们一起做了什么”，避免机构新闻稿语气。

当没有可报名活动时，不展示虚假内容，使用真实空状态：

> 下一次实验正在准备。先加入社群，第一时间收到通知。

### 5.6 真实创造者与项目

以实验档案卡呈现人物和项目，而不是包装成已经成功的案例。每张卡片包括：

- 人物姓名或项目名称；
- 所在高校、方向或角色；
- 当前正在解决的问题；
- 一次具体的尝试、失败或发现；
- 当前版本或进度状态；
- 一句真实经验。

素材不足时，本区减少卡片数量或暂时隐藏，不虚构人物、项目、融资或成果。

### 5.7 加入下一次迭代

页面底部设置三个分层入口：

1. `我是创业者 / 加入创业者社群`
2. `我想参与 / 报名近期活动`
3. `我能提供资源 / 成为合作伙伴`

入口连接到现有表单、二维码、社群或联系方式。正式链接缺失时，按钮明确显示“入口准备中”，不跳转到无效页面。

### 5.8 页尾

- 品牌简述；
- 社交媒体与联系方式；
- 实验档案入口；
- 版权信息；
- 当前网站版本号与最后更新时间；
- 返回顶部按钮。

## 6. 视觉系统

### 6.1 色彩

- 纸张白：主背景，温暖而非纯白；
- 炭黑：正文与主要结构；
- 迭代橙红：品牌主强调色，用于主按钮、状态和关键短语；
- 电子蓝或荧光绿：仅用于少量 AI/运行状态信息；
- 灰阶：照片、档案背景、次级文本与网格。

强调色占比保持克制。页面应以内容和真实图像为主，不以大面积霓虹渐变制造“科技感”。

### 6.2 字体

- 中文正文与标题使用现代、清晰的无衬线黑体；
- 英文、数字、版本号和状态标签使用等宽字体；
- 标题大而直接，正文保持舒适行长与足够行距；
- 手写内容优先使用真实手绘图形或少量手写字体，不用于长段正文。

### 6.3 图像

- 优先使用真实活动、人物、产品制作过程、工作桌面与校园场景；
- 可以降低饱和度，加入复印、扫描、胶片或纸张颗粒感；
- 保留人物表情和动作中的真实感，不做过度磨皮；
- 允许使用产品截图、代码片段、草图和便签作为创造过程证据；
- 禁止使用无来源的虚构成功案例或典型商业图库。

### 6.4 图形语言

- 手绘箭头、圈画、划线、便签、胶带、订书钉和边缘批注；
- 坐标纸、网格、实验编号、时间戳和版本状态；
- 每屏最多保留一至两个主要手工视觉焦点；
- 图形必须服务阅读层级，不得遮挡正文或导致移动端拥挤。

### 6.5 版式

- 使用大字号宣言、克制留白和不完全对称的编辑式布局；
- 重要内容保持清晰栅格，手写元素只负责打破机械感；
- 页面整体像一本由中国大学生创业者共同编辑的实验手册；
- 视觉目标是 Notion 的清晰、小红书的活人感、实验室笔记的未完成感，以及 AI 创造者工作台的专业度。

## 7. 文案原则

### 7.1 语气

- 像学长学姐交流：真诚、直接、有经验但不居高临下；
- 少用“赋能、引领、重塑、颠覆”等空泛机构用语；
- 多用具体动作：做出来、放进市场、找用户、验证、复盘、再试一次；
- 不制造焦虑，不承诺快速成功；
- 不把创业者写成被动接受帮助的人，而是共同创造者。

### 7.2 中英文关系

网站以中文为主。英文仅用于短状态和创造者语境，例如：

- `BUILDING`
- `PMF TEST`
- `ITERATION 03`
- `EXPERIMENT LOG`
- `WORK IN PROGRESS`

英文不承担核心信息，避免造成美式创业机构的疏离感。

## 8. 动效与交互

### 8.1 首屏进入

`DELTA X / ITERATION 未来`、实验编号和运行状态按顺序轻量加载，主宣言随后出现。动画总时长短，不设置必须等待的开场。

### 8.2 滚动叙事

页面滚动时，侧边或顶部版本标记按内容更新：

`IDEA_01 → BUILD_02 → TEST_03 → ITERATE_04`

版本标记是叙事线索，不应遮挡内容。

### 8.3 微交互

- 手绘箭头、圈画和划线采用轻微绘制动画；
- 按钮悬停呈现状态切换或版本更新感；
- 活动卡片提供清晰的悬停与键盘焦点反馈；
- 人物与项目档案可横向浏览，但核心信息不依赖滑动才能读取；
- 尊重系统“减少动态效果”设置，关闭非必要动画。

### 8.4 移动端

- 维持单列阅读和大标题；
- 压缩装饰图形和复杂动效；
- 活动时间、地点和状态始终优先可见；
- 主要行动按钮具有足够触控区域；
- 不使用横向滚动承载必读正文。

## 9. 内容与数据组织

首期内容采用可维护的结构化数据组织，即使页面是静态站点，也将活动、人物、项目和链接从展示组件中分离。

建议数据对象：

- `siteMeta`：品牌信息、网站版本、更新时间；
- `activities`：标题、日期、地点、状态、图片、报名链接；
- `builders`：人物或项目名称、方向、当前问题、实验片段、状态；
- `ctaLinks`：社群、活动报名、合作入口；
- `supportStages`：迭代阶段与 Delta X 支持内容。

数据流为：结构化内容 → 对应页面区块 → 状态化展示 → 外部行动入口。首期不建设后台管理系统，避免超出品牌官网所需范围；后续更新可通过编辑内容数据完成。

## 10. 技术与组件边界

首期按 Sites 托管的响应式单页网站设计，组件职责保持清晰：

- `Header`：导航、品牌与主行动入口；
- `Hero`：核心主张和首屏图像；
- `Manifesto`：价值理念；
- `IterationLoop`：迭代框架；
- `ActivityLog`：近期活动和状态；
- `BuilderArchive`：人物与项目档案；
- `JoinPanel`：三个加入入口；
- `Footer`：联系、版本和版权；
- `AnnotationLayer`：只负责装饰性手绘图形，不承载必读信息；
- `MotionController`：统一管理滚动与减少动态效果策略。

任何组件都不应同时承担内容数据、视觉装饰和页面导航三种职责。首期不引入登录、支付、站内报名后台或复杂 CMS。

## 11. 异常与缺失状态

- 活动数据为空：展示“下一次实验正在准备”的空状态和社群入口；
- 图片缺失：使用品牌化实验编号卡，不显示破损图片；
- 外部链接缺失：显示“入口准备中”，按钮不可触发；
- 外部链接打开失败：保留可复制的联系方式或二维码替代入口；
- 动效不支持或被关闭：所有内容保持完整可读；
- JavaScript 未加载：核心文字、图片和链接仍可访问；
- 小屏或慢速网络：优先加载正文与首屏关键图像，延后非必要装饰。

## 12. 可访问性与性能

- 正文和按钮颜色满足清晰对比；
- 所有交互均提供键盘焦点状态；
- 图片提供有意义的替代文本；
- 装饰图形不进入辅助阅读顺序；
- 不使用仅靠颜色表达的活动状态；
- 支持减少动态效果；
- 优化真实照片尺寸和格式；
- 避免使用体积过大的视频或无必要的第三方脚本；
- 首屏在常见移动网络下优先展示可读内容。

## 13. 验收标准

### 13.1 内容与品牌

- 访客在首屏能够理解 Delta X 的核心价值，而不只是知道它是一家孵化器；
- 页面清楚表达“为中国大学生补齐创业要素”；
- 品牌语气像学长学姐，不像投资机构或成功学导师；
- 不出现虚构活动、人物、项目或成果。

### 13.2 视觉

- 同时具备活人感、实验感、科技感和创造者气质；
- 手写与涂鸦元素不破坏阅读；
- 不落入典型美式加速器或通用 AI 公司模板；
- 桌面端和移动端均具有清晰层级。

### 13.3 功能

- 导航锚点正确；
- 所有已配置行动入口可用；
- 活动状态和空状态显示正确；
- 无外部链接时不会跳转至错误页面；
- 页面在禁用非必要动效后仍完整可用。

### 13.4 测试范围

- 桌面宽屏、常见笔记本宽度与手机视口；
- Chrome/Edge 与 Safari 兼容性；
- 键盘导航、焦点状态与减少动态效果；
- 图片缺失、活动为空、链接缺失等异常状态；
- 页面加载速度、图片尺寸与基础可读性；
- 上线后生产地址、社群入口、报名链接和合作方式的最终检查。

## 14. 首期素材清单与缺失处理

优先收集以下真实素材：

1. Delta X 标志或标准字；
2. 3 至 8 张活动、共创、产品制作或校园空间照片；
3. 近期活动信息与报名入口；
4. 2 至 4 位创业者或项目的真实实验片段；
5. 社群加入方式；
6. 合作联系方式；
7. 社交媒体账号。

素材不足不阻止首版建设。首版按以下规则降级：活动与人物卡减少数量，图片位置使用品牌化实验编号卡，行动入口显示准确状态。任何情况下都不使用虚构成果填充版面。

## 15. 范围边界

首期包含：

- 品牌单页官网；
- 响应式桌面与移动布局；
- 轻量滚动与手绘动效；
- 活动、人物/项目、加入入口；
- Sites 保存、部署与上线检查。

首期不包含：

- 用户账号系统；
- 站内支付；
- 独立活动报名后台；
- 复杂内容管理系统；
- 投资人或项目方数据门户；
- 自动化 CRM 或社群运营系统。

这些能力只有在真实运营需求出现后再独立设计，避免品牌官网首版过度建设。

## 16. 最终体验判断

当一位拥有 AI 项目的大学生打开网站，他不应感到自己正在被一家机构筛选，而应感到自己进入了一群真实创造者的实验现场：这里有人比他早走了两步，愿意分享经验、搭建连接，也期待他亲手做出下一个版本。

官网最终要留下的不是“Delta X 很成功”，而是：

> 我也可以先做出一点东西。
>
> 我不必独自开始。
>
> 我的未来，可以从下一次迭代开始。
