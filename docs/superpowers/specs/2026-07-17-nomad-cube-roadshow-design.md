# Nomad Cube 五分钟路演稿写作设计

## 1. 交付目标

结合《第38位-Nomad Cube移动3D打印机器人-郑尧涵.pptx》的 26 页实际画面与郑尧涵提供的文字底稿，撰写一份可直接排练、可随 PPT 逐页演讲的五分钟中文路演稿。

沟通任务：演讲结束时，评委应当相信 Nomad Cube 以移动机器人重构 3D 打印设备，已经形成“超自身尺寸打印、可靠拼接、移动中精准打印”的技术闭环，并具备从原型验证走向产品落地和持续经营的潜力。

## 2. 受众与表达方式

- 受众：创新创业赛事评委，兼顾技术、产品与商业判断。
- 演讲者：Nomad Cube 团队负责人郑尧涵。
- 总时长：5 分钟。
- 建议字数：约 1100—1250 个汉字。
- 风格：真诚、自信、克制，保留个人造物故事，不使用论文式长句或堆砌口号。
- 讲述原则：技术概念先讲“解决了什么问题”，再简述“如何做到”；商业信息只保留能够证明需求、差异化和可持续收入的部分。

## 3. 五分钟叙事结构

### 第一幕：为什么要做（P1—P7，约 60 秒）

以“一次性筷子木剑”为记忆点，从折纸、拼豆、积木和黏土过渡到大学里的 3D 打印剑。先建立“让普通人自由造物”的个人动机，再指出现有 3D 打印的两项限制：成型空间受设备约束，创作流程依赖人工切换。P7 用“距离真正的自由造物还有很长一段距离”完成问题收束。

### 第二幕：我们如何解决（P8—P13，约 105 秒）

由《流浪地球2》的移动机器人获得启发，提出“把盒子拆掉，让打印机动起来”。依次解释：

1. 分层多区切割与路径规划，使机器人能够分块连续打印；
2. 环境感知、智能建模、路径规划、移动打印形成软硬件闭环；
3. 四足三自由度移动平台突破固定腔体；
4. 斜面搭接、热风熔合和视觉闭环校准，将拼接误差控制在 3 mm 以内；
5. 渐进式打印、双同步带结构与重心动态调整，保障移动打印的稳定性和精度。

技术页不逐项朗读图中文字，只说清三项核心能力：“能走、能接、能打准”。

### 第三幕：产品和商业价值（P14—P21，约 85 秒）

P14 为产品正式亮相，留出短暂停顿。P15—P17 将 Nomad Cube 定义为“流动的制造能力”和“私人创意助手”，说明从一站式建模、切片、下发打印，到创意社区和模型内容的完整体验。

P18 用消费级桌面打印机和工业移动打印设备作为参照，突出“移动、大尺寸、低成本”的定位，谨慎使用 PPT 已展示的 6500 元价格和小于 3 mm 拼接误差。

P19—P21 合并讲述商业逻辑：核心技术自研自控，生产采用模块化与代工协同；目标用户覆盖 C 端创作者与 B 端小微机构；收入由硬件模块、专用耗材、模型订阅、维修支持与打印服务组成，形成一次购买、持续收益的闭环。

### 第四幕：为什么是现在、为什么是我们（P22—P26，约 50 秒）

用世界数字教育大会展示、12 批国内外参访团和 510 余人次接待证明项目已开始落地，并说明配套平台已经为服务订阅、耗材复购和订单转化做好准备。

P23 按“2026 产品落地—2028 规模布局—2030 生态构建”概括发展路径。团队与导师信息作为口头补充放在 P23，不虚构 PPT 未呈现的成员履历或成果。

P24—P26 回到开场的“自由造物”，以“造物不应受制于盒子的边界，梦想不应止步于工具的匮乏”收束，并以“让创意自由行走”结束。

## 4. Markdown 交付格式

最终文件放在 `01三两的打工tasks/Nomad Cube/` 目录，建议文件名为 `Nomad Cube 五分钟路演稿.md`。

文件结构：

1. 标题与版本说明；
2. 演讲总时长、建议语速和使用方式；
3. 按 P1—P26 编排的完整口播；
4. 每页包含页码、画面主题、该页建议时长和自然翻页提示；
5. 文末附一份“脱稿记忆骨架”，只保留各段关键词；
6. 对需要现场确认的信息使用排练备注，不在正式口播中保留不确定表述。

## 5. 内容边界

- 以用户提供的文字、PPT 画面和仓库现有的 Nomad Cube One Page 为事实基础。
- 不新增未经材料支持的订单额、销量、融资额、专利数量或性能数据。
- “无限尺寸”表述改为条件化表达：理论上在耗材、电量和作业环境持续满足的情况下，可突破传统打印腔体的尺寸限制。
- 不逐字朗读 PPT；讲稿负责解释页面结论、衔接前后逻辑。
- 不重复讲述生产与营销策略，商业模式集中在 P19—P21 一次讲清。

## 6. 完成标准

- 正文在正常比赛语速下可于 4 分 40 秒至 5 分钟内完成。
- 26 页均有对应口播或明确的快速翻页安排。
- 开场个人故事能够在一分钟内导入问题。
- 三项核心技术各自回答一个明确难题，术语准确且评委容易听懂。
- 商业部分说明目标用户、差异化、变现方式和当前落地进展。
- 结尾回应开场，并形成可记忆的团队口号。

## 7. 自检结果

- 无 `TBD`、`TODO` 或未决定事项。
- 叙事时长合计 300 秒，与五分钟要求一致。
- 页码范围覆盖 P1—P26，与实际 PPT 页数一致。
- 技术、产品、商业和愿景之间不存在重复段落或逻辑冲突。
- “团队介绍”被明确作为 P23 的口头补充，解决了底稿内容与 PPT 页面之间的错位。
