# Delta X 首页活动模块：混合时间线、日历与日夜主题

日期：2026-07-28  
状态：待用户书面审阅  
实施范围：仅修改独立的首页框架原型；不修改 `deltaxworld.cn` 活动官网源码，不接入正式内容后台。

## 1. 目标

把首页活动模块从“活动标题目录 + 单张大图”改成能同时表达两件事的结构：

1. 让访客第一眼看到正在发生和即将发生的活动，保留报名转化能力。
2. 通过连续的年份、日期与活动类型，呈现 Delta X 活动体系如何持续进化，而不是陈列几张互不相关的海报。

参考 Luma 的活动列表与日历联动方式，以及 MU Shanghai 用连续阶段组织活动主题的方式。只借鉴信息结构与交互，不复制它们的品牌视觉。

## 2. 信息架构

活动模块采用桌面端双栏结构：

- 左侧约 68%：混合时间线与活动卡片。
- 右侧约 32%：粘性日历卡片与完整活动日历入口。
- 模块顶部：章节标识、活动状态说明、日夜主题切换。

左侧时间线从访客最需要的内容开始，按以下顺序排列：

1. `NOW / 即将发生`：正在报名、即将开始或正在进行的活动。
2. `2026`：按月份和日期倒序排列的已发生活动。
3. `2025` 及更早年份：继续向下回溯。

这种顺序兼顾报名转化与发展回顾。时间线虽然从现在向过去阅读，但节点样式会通过年份、类别与阶段标签说明 Delta X 从早期单点活动逐渐形成高校 Builder、Founder、Delta Bites、产业合作等连续活动体系。

## 3. 左侧时间线

### 3.1 时间轴

- 使用一条细竖线连接全部活动节点。
- `NOW` 节点使用 Delta 橙色实心点；已结束活动使用暖灰色空心点。
- 每个年份作为一级分组，月份或具体日期作为二级节点。
- 年份、日期和状态使用小字号无衬线字体；活动标题使用克制的中等字号，不再使用海报式大标题。

### 3.2 活动卡片

每张卡片只保留必要信息：

- 日期与时间
- 状态：报名中、进行中、活动回顾
- 活动标题
- 类型或合作方的一行信息
- 小尺寸真实海报或现场照片
- `查看活动` 或 `查看回顾` 入口

默认突出 `NOW` 中第一场可报名活动；如果没有未来活动，则突出最近一次已结束活动。卡片之间保持清晰间隔，但不使用夸张圆角、阴影或大面积渐变。

### 3.3 进化表达

发展过程不依靠额外长文解释，而由三个层次共同呈现：

- 时间层：年份与日期连续推进。
- 类型层：每张卡片显示活动系列或目标人群。
- 视觉层：当前节点为橙色，越早的节点逐渐弱化；滚动时当前年份与阶段保持可见。

## 4. 右侧日历卡片

日历卡片参考 South Park Commons 的 Luma 页面，但缩减功能，只保留首页需要的部分：

- 当前月份标题与前后月切换。
- 星期标题与日期网格。
- 有活动的日期显示小圆点；正在报名的日期使用橙色圆点，已结束活动使用灰色圆点。
- 点击有活动的日期，左侧滚动并高亮对应活动卡片。
- 点击左侧活动卡片，日历同步切换到该活动月份并选中日期。
- 日历下方提供 `进入 Delta Events 完整活动日历` 的明确入口。

日历卡片在桌面端随时间线滚动保持可见。移动端改为时间线上方的可折叠月份卡片，避免占用横向空间。

## 5. 日夜主题

### 5.1 白天模式

- 页面底色：`#F1EEE6`
- 次级底色：`#E7E2D7`
- 主文字：`#141412`
- 次级文字：`#6C6860`
- 活跃强调：`#ED5A22`

### 5.2 黑夜模式

继承 `deltaxworld.cn` 的核心品牌色：

- 页面底色：`#111111`
- 卡片底色：`#191919`
- 主文字：`#FBF6EE`
- 次级文字：`#8F8F8F`
- 活跃强调：`#FD6509`
- 分隔线：暖白色低透明度

不使用蓝紫科技渐变、发光边框或霓虹效果。黑夜模式应像克制的活动档案，而不是 AI 产品后台。

### 5.3 切换规则

- 导航右侧设置尺寸克制的 `日 / 夜` 图标按钮。
- 首次访问读取系统主题；用户切换后写入浏览器本地存储。
- 主题切换只使用短暂的颜色过渡，不做整页翻转或强烈动画。
- 按钮支持键盘操作，并提供可读的无障碍标签。

## 6. 字体与密度

- 时间线年份：20–24px。
- 日期与状态：11–13px。
- 活动标题：18–22px，行高 1.25–1.35。
- 活动说明：13–15px，行高 1.45–1.55。
- 日历月份标题：18–20px。
- 日历日期：12–14px。

整个模块依靠图像、时间线和节奏建立层次，不通过放大字体制造视觉冲击。

## 7. 数据与异常处理

当前本地 `events.js` 中多数活动缺少可用的 `date` 与 `dateSort` 值。因此：

- 框架原型使用明确标注的示例日期验证结构和交互。
- 正式内容阶段必须补齐活动开始日期、结束日期、状态与详情链接，或接入现有活动日历数据源。
- 缺少日期的活动进入 `未标注日期` 分组，不伪造日期，也不显示在日历网格上。
- 没有未来活动时显示克制的空状态，并把最近一次活动回顾作为默认选中项。

## 8. 响应式与可访问性

- 桌面端：时间线与粘性日历双栏。
- 平板端：时间线约 62%，日历约 38%。
- 手机端：日历折叠到时间线上方，活动卡片改为单栏，图片保持小尺寸。
- 所有可点击节点具备清晰焦点状态。
- 支持键盘切换活动和月份。
- 用户开启减少动态效果时，取消滚动定位动画和主题颜色过渡。

## 9. 验收标准

1. 首屏内能同时看到至少一个时间线节点、一张活动卡片和日历卡片。
2. 时间线默认突出正在报名或最近发生的活动。
3. 点击日历日期能定位活动；点击活动能同步日历月份与日期。
4. 日夜切换覆盖活动时间线、卡片、日历、导航和分隔线，并在刷新后保留选择。
5. 活动标题在 1440px 桌面宽度下不超过 22px；正文不超过 15px。
6. `deltaxworld.cn` 保持独立且不被修改，首页只提供明确跳转入口。
7. 没有日期的数据不会被伪造，也不会造成脚本错误。
