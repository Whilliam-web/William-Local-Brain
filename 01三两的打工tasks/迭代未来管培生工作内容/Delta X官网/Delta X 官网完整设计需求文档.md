# Delta X 官网完整设计需求文档

> 使用方式：将本文件全文提交给网站设计或开发助手。对方应先理解品牌和网站目标，再进行设计与实现；如无重大信息缺失，不要重新发散品牌方向。

## 一、设计任务

为 **Delta X 迭代未来** 设计并实现一个年轻、开放、有实验感，同时具备专业科技气质的品牌官网。

官网的第一任务不是展示一家已经功成名就的投资机构，而是让中国年轻创造者感到：

> 这里有一群比我早走两步的人，愿意陪我把第一个版本做出来，并把我连接到真实用户、产业和资本。

第一版优先设计为一页式品牌官网。访客应当在 30 秒内理解 Delta X 是谁、相信其价值理念，并知道下一步如何查看活动、加入社群或建立合作。

## 二、品牌基础信息

### 2.1 品牌名称

- 中文及主要名称：**Delta X 迭代未来**
- 英文简称：**DELTA X**
- 视觉符号可使用：**ΔX**

### 2.2 品牌定位

Delta X 迭代未来是一家由浙大学生自主发起、关注中国年轻人原生创新与 PMF 商业闭环的早期孵化器，聚焦 AI 应用落地。

作为浙大 X-Lab 创投生态向市场侧延伸的重要实践场景，Delta X 为学生和年轻创业者提供资本与产业命题、技术基建、团队招募、活动链接等支持，帮助项目在真实市场中快速验证与迭代成长，让学生在创业实践中从想法走向产品、从学习走向创造。

### 2.3 核心价值主张

Delta X 致力于为中国大学生配齐创业要素。

我们不要求年轻人一次性改变世界，而是鼓励他们在一次次真实的 Build、Test 和反馈中，把自己的未来迭代出来。

### 2.4 核心品牌句

主标题优先使用：

> 不用一次改变世界。一次次，把自己的未来迭代出来。

辅助表达：

> 从想法到产品，从学习到创造。

> 让想法进入真实市场，让每一次 Build 都成为下一次出发。

## 三、网站目标与用户路径

### 3.1 核心目标

网站需要依次完成以下任务：

1. 让访客理解并认同 Delta X 的价值理念。
2. 解释 Delta X 如何帮助年轻创造者从想法走向真实市场。
3. 展示近期真实活动和正在发生的事情，建立可信度与“活人感”。
4. 引导访客加入创业者社群、报名活动或发起合作。

### 3.2 主要用户

#### A. 有 AI 项目的大学生创业者和创新者

他们想知道这里是否理解年轻人的处境、能提供什么支持、是否有真实实践机会，以及如何加入。

#### B. 潜在投资人

他们想判断 Delta X 的价值理念、项目来源、组织能力和年轻创造者网络是否真实、持续且专业。

#### C. 产业及生态合作伙伴

他们想了解 Delta X 是否能够连接高校青年、承接产业命题、组织活动并推动产品落地。

### 3.3 理想浏览路径

```text
看见主张
  ↓
理解价值理念
  ↓
看懂迭代框架与支持要素
  ↓
看到近期真实活动和创造者故事
  ↓
加入社群 / 报名活动 / 发起合作
```

## 四、品牌人格

如果 Delta X 是一个人，他不是一位高高在上的成功企业家或天使投资人。

他更像一位只比你大两岁的学长或学姐：

- 已经在 AI 和创业方面做出了一些真实成果；
- 愿意把踩过的坑和做事方法告诉你；
- 不替你做决定，但愿意陪你完成第一轮验证；
- 能在需要时帮助牵线，连接技术、伙伴、产业和资本；
- 专业但不端着，开放但不轻浮；
- 仍在持续 Build，故事没有结束。

网站所有文案和交互都应保持这一人格：真诚、直接、有行动感，不使用空泛宏大、居高临下或传统机构式话术。

## 五、整体创意方向

采用以下组合方向：

### 5.1 主方向：创造者实验日志

网站像一份仍在进行中的实验日志、产品草稿和 Builder 手册。使用编号、版本号、实验阶段、手写批注、划线、箭头、便签和未完成标记，体现持续探索与迭代。

### 5.2 内容补充：真实人物与真实活动

通过近期活动、共创现场、创造者问题和成长片段带来“活人感”。如果获得真实人物照片，应优先使用真实现场和自然状态，不使用千篇一律的商务合影或图库式 AI 人物。

### 5.3 交互补充：少量科技化微交互

使用克制的阶段切换、状态灯、滚动高亮、坐标或扫描线等细节体现 AI Native 与 Build 精神。交互服务于信息理解，不做炫技型 3D、大量粒子或影响性能的动画。

## 六、视觉设计语言

### 6.1 视觉关键词

- 立足中国
- 中国新青年
- 高校青年
- AI Native
- 创造者文化
- 黑客松精神
- 动手 Build
- 实验与草稿
- 社群组建
- 年轻、开放、真实
- 专业、科技、未来
- Future Builders

### 6.2 参考气质

- [SparkLab](https://www.sparklab.city/)：页面节奏、年轻能量和品牌表达参考。
- Notion：清晰、友好、工具感和人的温度。
- 小红书：真实人物、生活感、成长感和内容亲近度。
- South Park Commons：创造者社群、同伴感和在路上的气质。
- YC：简洁、明确、技术创业的专业可信度。

参考网站只用于理解气质和信息组织，不应直接复制其布局、插画、字体或品牌资产。

### 6.3 色彩建议

主色系统：

- 实验纸张色 / 暖米白：作为主要背景，避免纯白机构感。
- 深黑：用于大标题、结构线和专业信息。
- Delta 橙红：作为最强品牌色，用于 CTA、手写强调和关键区域。

辅助信号色：

- 酸性绿：用于运行状态、实验编号或少量科技信号。
- 淡蓝或浅粉：仅用于便签、档案卡和内容分组。

色彩应保持高对比和克制，不使用大面积常见 AI 蓝紫渐变。

### 6.4 字体与排版

- 中文标题：粗体、紧凑、有海报感，可使用现代黑体。
- 正文：清晰易读的中文无衬线字体。
- 英文编号、版本、标签：等宽字体或技术感字体。
- 允许同一标题出现印刷体与手写批注叠加，但必须确保可读性。
- 大标题可有强烈尺度差，正文保持舒适行长和足够留白。

### 6.5 图形与材质

可以使用：

- 手写线条、箭头、圈选和下划线；
- 实验编号、版本号、日期戳和状态标签；
- 方格纸、网格、扫描线和轻微纸张纹理；
- 胶带、便签、档案卡和打印稿式构图；
- 不完全对齐的草稿感，但页面主网格必须稳定。

避免：

- 冷冰冰的传统孵化器或金融机构风格；
- 大量玻璃拟态、蓝紫渐变、发光球体和抽象 AI 脑图；
- 过度儿童化的涂鸦；
- 没有信息目的的装饰和复杂动效。

## 七、页面信息架构

第一版采用单页官网，导航锚点清晰。建议结构如下。

### 7.1 顶部导航

左侧：`ΔX / Delta X 迭代未来` 品牌标识。

导航项：

- 理念
- 迭代框架
- 最近发生
- 加入

右侧主按钮：`加入下一次迭代 ↗`

桌面端可使用轻量吸顶；移动端折叠为简洁菜单。导航不应遮挡正文。

### 7.2 Hero：第一眼主张

核心标题：

> 不用一次改变世界。一次次，把自己的未来迭代出来。

简短说明：

> Delta X 为中国大学生补齐创业要素，让想法进入真实市场，让每一次 Build 都成为下一次出发。

主 CTA：`看看我们如何陪你迭代 ↘`

次 CTA：`加入创造者社群 ↗`

视觉上可以叠加手写“迭代出来”、实验版本号、当前状态和便签式注释，让页面像一份刚刚被打开的 Builder 草稿。

### 7.3 价值理念：年轻人不缺想法

主标题：

> 年轻人不缺想法，缺的是把第一版做出来的条件。

核心观点：

- 年轻人不缺改变世界的想法，缺的是把第一个版本做出来的条件。
- 创业不是一次正确答案，而是一连串来自真实用户的反馈。
- 从作品走向产品，从可能性走向可持续，每一步都值得被认真对待。

支持要素可沿页面底部形成一条“补齐清单”：

- 资本与产业命题
- AI 技术基建
- 团队与伙伴招募
- 活动和生态连接
- 真实市场验证

### 7.4 迭代框架：从想法到真实需要

主标题：

> 从想法，到有人真的需要。

五个阶段：

1. `IDEA_01 / 发现问题`：去现场，看见真实存在、值得解决的问题。
2. `BUILD_02 / 快速 Build`：让想法离开文档，成为可被使用的最小版本。
3. `TEST_03 / 用户验证`：把产品交给真实的人，观察他们留下或离开的原因。
4. `PMF_04 / 找到 PMF`：找到谁真正需要它，以及价值如何形成闭环。
5. `ITERATE_05 / 再次迭代`：带着证据修改产品、团队和判断。

每个阶段需要同时显示 Delta X 能提供的对应支持。滚动时可以高亮当前阶段，但必须保留完整静态可读性。

### 7.5 近期活动：最近，我们正在做什么？

保留深色、带运行状态的实验区域，与前面的暖色纸张形成节奏变化。

展示规则：

- 自动展示 3–5 场“进行中”或“即将开始”的活动；
- 第一场使用大型重点卡片，其余使用紧凑卡片；
- 显示状态、名称、活动类型、主办角色、简短介绍和海报；
- 有有效链接时显示“查看活动”或“立即报名”；
- 没有链接时显示“详情即将发布”；
- 有日期才显示日期，不虚构缺失信息；
- 海报加载失败时使用 Delta X 橙黑色实验编号占位图；
- 底部显示“查看全部 N 场活动 ↗”，链接至 [Delta Events 活动官网](https://deltaxworld.cn/)。

### 7.6 创造者档案：我们相信创造者都还在路上

用 3 张手稿、便签或档案卡呈现真实创业问题，而不是堆砌虚构成功案例。

示例问题：

- 有人真的会在每周重复使用它吗？
- 这是一个被想象的问题，还是每天都会发生的问题？
- 今天能不能做出一个可以被拒绝的版本？

这一部分传递陪伴、反思和成长感。后续获得真实项目授权后，可逐步替换为真实 Builder 档案。

### 7.7 最终行动区：下一版，和我们一起做

使用大面积 Delta 橙红，形成明确收束。

三个入口：

1. `加入创业者社群`：面向大学生 Builder 和正在做产品的人。
2. `报名近期活动`：滚动至近期活动区域。
3. `成为合作伙伴`：面向投资人、产业方和高校生态伙伴。

未准备好的链接不得伪造。入口未配置时应明确显示“入口准备中”，或提供真实可用的联系渠道。

### 7.8 页脚

包含：

- 品牌名称与一句话主张；
- 联系方式和真实社交媒体入口；
- 活动官网链接；
- 网站版本号、最近更新时间或 `BUILD IN PUBLIC` 状态；
- 必要的备案及版权信息。

## 八、活动内容自动接入要求

### 8.1 强制边界

**不得对现有活动官网做任何变动。**

禁止修改以下内容：

- `https://deltaxworld.cn/` 的页面、代码和资源；
- 活动官网域名、Cloudflare 配置及部署流程；
- 活动官网的飞书多维表格和同步程序；
- 活动数据和现有报名链接。

所有接入逻辑只能写在 Delta X 主站。

### 8.2 数据来源

主站只读公开地址：

`https://deltaxworld.cn/events.js`

该文件由活动官网现有流程生成。主站不得执行其中的外部 JavaScript，只能安全提取 `window.DX_EVENTS = [...]` 中的 JSON 数组。

### 8.3 推荐架构

```text
飞书多维表格
  ↓ 活动官网现有同步链路，完全不动
活动官网 events.js
  ↓ 公开只读
Delta X 主站 /api/events
  ├─ 成功：校验、规范化、缓存
  └─ 失败：最近成功数据或内置快照
  ↓
主站近期活动模块
```

具体要求：

- 外部读取超时为 3 秒，不得阻塞首页；
- 成功数据缓存 10 分钟；
- 仅接受合法标题、状态、描述、海报路径和 `http/https` 链接；
- 只展示 `live` 和 `upcoming`；
- 最多展示 5 条；
- 失败时依次使用最近成功数据、内置快照和现有空状态；
- 不向普通访客展示技术错误弹窗；
- 活动官网 `events.js` 更新后，主站刷新应在 10 分钟内看到变化。

## 九、交互与动效

动效应像产品正在运行，而不是品牌宣传片。

推荐：

- Hero 手写线条轻微绘制出现；
- 迭代框架随滚动高亮当前阶段；
- 状态灯以低频率呼吸；
- 卡片悬停出现编号、边框或轻微位移；
- 锚点跳转平滑但不过慢；
- 尊重系统 `prefers-reduced-motion`。

禁止：

- 强制滚动接管；
- 长时间首屏 Loading；
- 影响阅读的循环动画；
- 移动端高耗能视差和大量粒子。

## 十、响应式与可用性

- 优先保证桌面端和手机端，不要求复杂平板专属布局。
- 移动端标题应重新换行，不做简单等比缩小。
- 所有按钮、链接和菜单具有明确的键盘焦点状态。
- 正文、标签和按钮达到基本对比度要求。
- 图片提供替代文本；装饰性涂鸦不应干扰屏幕阅读器。
- 页面在 JavaScript 较慢时仍应尽量保留品牌主张和基本结构。
- 不应因外部活动数据失败而白屏或产生 5xx。

## 十一、技术与性能要求

- 使用适合当前托管环境的轻量前端方案，避免不必要的大型依赖。
- 首屏内容应快速显示，不依赖活动官网才能渲染。
- 生产入口必须符合 Sites / Cloudflare Worker 的 `fetch` 处理器要求。
- 所有外部资源均应有失败回退。
- 不在代码中暴露密钥、飞书凭证或内部数据。
- 保持语义化 HTML、合理页面标题和描述，支持基础 SEO 和社交分享。

## 十二、交付内容

设计与开发助手应完成：

1. 可运行的单页品牌官网；
2. 桌面端和移动端完整视觉；
3. 所有页面区块、文案和交互状态；
4. 活动数据只读自动接入及失败回退；
5. 真实可用的导航和 CTA 状态；
6. 自动化测试、生产构建和真实浏览器验证；
7. 部署后的公开网址和版本说明。

如果社群、合作或联系链接尚未提供，应保留清晰的配置位置和诚实的未开放状态，不得自行编造二维码、邮箱、人物、项目成绩或合作案例。

## 十三、验收标准

### 品牌与内容

- [ ] 访客 30 秒内能理解 Delta X 是谁、服务谁、相信什么。
- [ ] 首页首先突出价值理念，而不是机构履历和资源堆砌。
- [ ] 品牌人格像可信任的学长学姐，而不是高高在上的投资人。
- [ ] 同时具有活人感、实验感与专业科技感。

### 页面结构

- [ ] 完成 Hero、价值理念、迭代框架、近期活动、创造者档案、行动区和页脚。
- [ ] 导航锚点、按钮和活动入口均指向真实有效位置。
- [ ] 移动端没有文字溢出、遮挡和难以点击的问题。

### 活动接入

- [ ] 活动官网及其同步系统没有任何修改。
- [ ] 主站自动展示进行中和即将开始的活动，最多 5 场。
- [ ] 活动数据更新后 10 分钟内可在主站看到。
- [ ] 活动官网不可访问时，主站仍能快速打开并显示回退内容。

### 质量

- [ ] 自动化测试通过。
- [ ] 生产构建通过。
- [ ] 桌面端和手机端完成真实浏览器检查。
- [ ] 公开网址无 522、白屏或关键资源错误。

## 十四、明确不做的内容

第一版不需要：

- 复杂后台管理系统；
- 用户注册登录；
- 项目融资数据看板；
- 虚构团队和成功案例；
- 多语言版本；
- 大型 3D 场景或高性能成本动效；
- 对活动官网的任何修改。

## 十五、给设计与开发助手的最终指令

请先理解并认同 Delta X 的价值理念，再开始设计。
