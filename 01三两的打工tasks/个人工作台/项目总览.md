# 个人工作台项目总览

## 当前状态

A 版编辑部式首页已经部署到本地 Obsidian：使用深色氛围首屏、高密度三栏 Markdown、原生 Bases、Homepage 4.4.4、Dataview 0.5.68（仅 DQL）和专用 CSS snippet。Homepage 启动时自动打开 [[个人工作台首页]] 的阅读视图；左栏展示今日入口与七日节奏，中栏展示当前焦点、动态项目和工作记录，右栏展示待判断、风险与最近更新。

数据从 2026-08-04 起自然积累，不回填历史日记，也不自动创建当天日记。当天尚无记录时，“今日脉搏”和“今日变化”会显示 0 个结果，但栏目骨架、开始入口和其他导航仍保持可见。

## 初始意图

- 形成统一的个人工作入口。
- 聚合任务、资料、决策与项目进展。
- 保留人对目标、权限、关键决策和最终输出的控制。

## 待确认

1. 连续使用每日变化与“今日收刊”一周，确认首页是否能温和促成每日回顾。
2. 根据一周真实数据调整首屏信息取舍、右栏更新条数和文字密度。
3. 暂不增加 Tasks、Meta Bind、DataviewJS 或外部服务；只有现有链路稳定后再评估更复杂的图表与交互。

## 当前边界

- 视频标题不构成工具或方案依据。
- 当前采用“原生骨架 + 最小插件增强”：原生 Markdown、Bases 和 Daily Notes 负责稳定记录；Homepage 只负责启动页与阅读视图；Dataview 只运行 DQL/inline DQL，DataviewJS 与 inline DataviewJS 均关闭。
- 暂不安装 Tasks、Meta Bind 或其他工作台增强插件，避免增加故障面。
- 每日备忘录承担每日变化流与“晚间收刊”的详细记录角色；项目工作记录和学习笔记仍为事实来源。
- 历史日记不回填、不改写；七日节奏允许显示历史日期，但新变化属性只从启用当天积累。
- 首页只呈现确认过的变化数量和收刊摘要，不使用文件修改次数替代工作成果。
- 首页中的 Daily Notes 入口仍由用户主动点击，不自动创建当天日记。
