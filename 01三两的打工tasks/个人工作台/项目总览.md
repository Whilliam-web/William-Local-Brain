# 个人工作台项目总览

## 当前状态

A 版编辑部式首页与本地插件 `Whiliam Workbench Memory` 已经部署：深色氛围首屏和三栏结构保持不变，中栏新增自动工作记忆流，监听正式工作、学习、规划和知识整理目录中的 Markdown 变化；750ms 内重复事件会折叠，活动数据本地保存 90 天，启动时补扫离线变化。首次启用只建立文件签名基线，不把整个旧知识库误报成今天的新工作。

[[历史业务记录索引]] 已从 25 份既有日记、3 份正式项目工作记录和项目记忆索引生成，共保留 263 条可追溯记录；原始文件没有被回填或改写。晚间复盘由用户确认候选后写回当天日记的受控标记块和属性，失败时不会被误记为完成。

2026-08-05 已完成首轮真实运行验收：插件在干净基线上建立 136 个受控文件签名且未产生假候选；一次正式工作记录修改被准确捕捉；晚间复盘从首页进入并创建当日日记；完整重启后事件 ID、候选数量和完成状态保持一致。当前实现已具备日常使用条件，但“能否稳定培养复盘习惯”仍需连续一周的实际使用数据，不能由一次技术验收替代。

2026-08-05 最终收尾工作按用户要求暂停。知识库中现有稳定部署保持不变，可以继续日常使用；独立源码仓库中另有一批尚未提交、尚未部署的可靠性改动。下次恢复时必须先完成 frontmatter 原文保真、已完成复盘路径修复有效性和后台补存失败提示三项收尾，再运行完整自动化与真实 Obsidian 回归，不能把开发中的改动直接覆盖到当前稳定版。

2026-08-09 已恢复并完成最终收尾：三个可靠性缺口均已补回归测试并修复，独立源码仓库最终提交为 `1314adc`（核心可靠性提交 `4fcda33`）；15 个测试文件、172 项测试、TypeScript、生产构建、历史索引构建与 11 项静态检查全部通过。插件三个部署文件与源码构建哈希完全一致。真实 Obsidian 验证覆盖手动刷新、当日自动候选、旧复盘重开与预填、YAML 注释／锚点／别名／merge key 原文保真、滚动稳定和完整重启持久化。技术交付已经完成；连续使用能否培养回顾习惯仍属于后续行为观察，不再作为软件验收阻塞项。

## 当前边界

- 视频标题不构成工具或方案依据。
- 当前采用“原生骨架 + 最小插件增强”：原生 Markdown、Bases 和 Daily Notes 负责稳定记录；Homepage 只负责启动页与阅读视图；Dataview 只运行 DQL/inline DQL，DataviewJS 与 inline DataviewJS 均关闭。
- 暂不安装 Tasks、Meta Bind 或其他工作台增强插件，避免增加故障面。
- 每日备忘录承担每日变化流与“晚间收刊”的详细记录角色；项目工作记录和学习笔记仍为事实来源。
- 历史日记不回填、不改写；历史索引只做只读提取并保留来源链接。
- 自动变化只是复盘候选，不把文件修改次数冒充工作成果；只有用户确认的内容才写入收刊。
- 平时不自动创建当天日记；用户完成晚间复盘时，如果当天日记不存在，则按 Daily Notes 配置和模板创建。
- 插件不联网，活动数据只写入 `.obsidian/plugins/whiliam-workbench-memory/data.json`。
