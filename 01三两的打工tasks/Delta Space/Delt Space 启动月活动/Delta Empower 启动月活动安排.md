# Delta Space 启动月活动筹备思路

> [!map] 执行总控图
> [[Delta Space 启动月活动筹备总控.canvas]]

> [!important] 当前权威结构
> 启动月采用 `Prologue → Step 1 → Step 2 → Step 3 → End`，每个 Step 原则上约 10 天。`Link` 归属于 Step 2，同时作为贯穿全程的能力存在。

## 一、活动概览

| 项目 | 当前共识 |
|---|---|
| 活动定位 | Delta Space 从 0 到 1 的启动月，也是 `Delta Chapter 0` |
| 时间框架 | 9 月，约 30 天；上旬、中旬、下旬分别承载三个 Step |
| 空间 | Delta Space；同时承担活动、共创、讨论、展示和入驻功能 |
| 核心人群 | Builders、潜在创业者、已有项目团队、高校学生 |
| 扩展人群 | 研究者、创意工作者、自由职业者、数字游民及愿意探索创新的人 |
| 核心机制 | 需求发现 → 共创构建与资源链接 → 验证复盘 → 留存续章 |
| 活动原则 | 非竞赛、非评分；重交流、重思考、重创新；允许不同成熟度并存 |

## 二、品牌主线

### 1. 一句话定位

> Delta Space 是校门口青年创新场，是学生从校园进入真实世界的早期接口。

### 2. 空间的双重属性

- **物理空间**：提供活动、讨论、共创、展示、办公和入驻的真实载体。
- **想法空间**：让想法诞生、讨论、碰撞、链接、试验并逐步落地。

### 3. 启动月要表达的价值

- 多元、开放、自由、迭代；
- 小步快跑，通过真实反馈持续验证；
- 活动形式只是外在框架，品牌内容与价值表达才是主干；
- 不只展示成功结果，也记录问题、失败、调整和参与者成长；
- 连接学校与社会，让年轻人更早接触真实需求、真实资源和真实协作。

## 三、启动月主线

### Prologue — 启动与招募

**目的**

- 完成 Delta Space 品牌亮相；
- 解释 `Delta Chapter 0` 和三个 Step 的参与机制；
- 给出报名、参加、合作与资源入口；
- 启动全流程内容记录。

**建议动作**

- 启动仪式：说明品牌定位、活动主线和参与方式；
- 发布招募视频、报名页、合作入口和资源入口；
- 收集参与者的问题、项目阶段、技能、需求和可提供资源；
- 为个人和团队建立全流程 Vlog／项目记录；
- 对成熟项目、早期项目和零起点参与者进行初步分层。

**阶段产出**

- 启动月统一叙事；
- 报名与参加机制；
- 初始参与者清单和项目档案；
- 内容记录方案；
- 外部合作与资源邀约清单。

### Step 1 — Demand & Discuss

**目的**

- 发现真实需求与尚未解决的问题；
- 形成问题意识、兴趣方向和早期判断；
- 通过讨论找到可能的共创伙伴。

**活动候选**

- 圆桌讨论、主题对话、播客、开放麦；
- 失败项目展、问题展、想法博物馆；
- 围绕行业现状和未满足需求的讨论；
- Day 1 扫描／观察任务：记录问题从哪里来；
- 伙伴发现、技能互认和初步组队；
- 小型午餐会、晚餐会和深度交流活动。

**阶段产出**

- 问题清单；
- 需求假设及其初步证据；
- 兴趣方向和参与者画像；
- 初步伙伴关系；
- 进入 Step 2 的共创命题。

**执行检查**

- [ ] 每场活动都对应明确的问题领域；
- [ ] 记录讨论结论，而不是只记录到场人数；
- [ ] 允许参与者提出自己的问题，也允许从企业／社会需求中选题；
- [ ] 对需求假设标记已证实、待验证或已证伪；
- [ ] 完成进入 Step 2 的人员与命题匹配。

### Step 2 — Build & Link

**目的**

- 把想法推进为可讨论、可试验、可展示的阶段成果；
- 在构建过程中完成伙伴、导师、企业和其他资源匹配；
- 让资源真正进入方案，而不是只做嘉宾露出。

#### Build：共创构建

**活动候选**

- AI Hack House、Hackathon；
- Workshop、Brainstorm；
- 企业命题、小型任务和短周期共创；
- 原有项目迭代、案例交流和阶段展示；
- 两三天内完成的小型原型或方案；
- 按项目成熟度设置不同任务和输出颗粒度。

#### Link：资源链接

`Link` 明确属于 Step 2，并在这一阶段集中发生；与此同时，伙伴发现、资源引入和关系维护贯穿整个启动月。

**链接对象**

- 共创伙伴与潜在合伙人；
- 学术导师、企业导师和行业专家；
- 企业、真实需求方和初创公司；
- 投资人、政府、高校、孵化机构、飞地和创新基地；
- 场地、设备、传播和社区资源。

**活动候选**

- Office Hour 和导师交流；
- 资源沙龙、行业分享和企业参访；
- 午餐会、晚餐会和小型匹配会；
- 企业需求对接、项目问诊和合作讨论；
- 合伙人／技能伙伴匹配。

**阶段产出**

- 原型、方案或阶段成果；
- 共创团队和伙伴关系；
- 资源匹配记录；
- 导师及真实需求方反馈；
- 下一步验证计划。

**执行检查**

- [ ] 每个项目明确当前成熟度和本阶段可交付成果；
- [ ] 每条资源链接记录需求、资源方、负责人和下一步；
- [ ] 避免成熟项目和早期想法采用同一套展示标准；
- [ ] Workshop、Hackathon 等形式必须服务于明确命题；
- [ ] 进入 Step 3 前形成可验证的问题或成果。

### Step 3 — Verification & Review

**目的**

- 通过真实反馈检验阶段成果；
- 形成复盘，决定继续、调整或停止；
- 让不同成熟度的参与者都能获得有价值的反馈。

**活动候选**

- 阶段 Show、Showcase、游园会和成果展；
- 导师门诊、行业嘉宾点评和真实用户反馈；
- 项目复盘会、同伴评议和经验分享；
- 成熟项目案例展示、早期项目过程展示；
- 失败原因、验证结果和下一轮假设整理；
- 创业公司真实实践分享，避免只讲书本知识。

**阶段产出**

- 验证结果与证据；
- 复盘结论；
- 继续／调整／停止判断；
- 项目成熟度分层；
- 后续行动、合作和入驻建议。

**执行检查**

- [ ] 每个展示都有明确的验证问题；
- [ ] 反馈来自真实用户、行业嘉宾或真实需求方；
- [ ] 不以统一排名替代分层反馈；
- [ ] 复盘同时记录有效方法和失败原因；
- [ ] 将值得继续的项目导向 End 的留存机制。

### End — Closing & Retention

**Closing**

- 举办闭幕式和成果回顾；
- 发布启动月全流程 Vlog 和参与者成长记录；
- 回顾问题、构建、链接、验证和复盘的完整路径；
- 宣布下一次 Delta Chapter 或持续活动安排；
- 将启动月定义为 Delta Space 的第一次完整迭代。

**Retention**

| 留存层级 | 定义 | 可用机制 |
|---|---|---|
| 核心留存 | 与 Delta Space 形成明确、持续的强关系 | 合作协议、正式入驻、加入组织、长期项目协作 |
| 边缘留存 | 保持弱连接并具备后续转化可能 | 好友、社群、资源库、订阅、后续系列活动 |

**执行检查**

- [ ] 为每个参与项目确定核心留存、边缘留存或暂不留存；
- [ ] 协议、入驻和长期协作必须有明确负责人和下一节点；
- [ ] 社群留存要有后续内容与活动，而不是只建群；
- [ ] 将本期经验沉淀为下一次 Delta Chapter 的输入。

## 四、参与者与资源

### 参与者分层

| 类型 | 特征 | 适合路径 |
|---|---|---|
| 成熟项目 | 已有产品、方案或明确进展 | 案例输出、资源链接、验证与入驻讨论 |
| 早期项目 | 已有问题或初步想法 | 需求讨论、共创构建、导师反馈和阶段验证 |
| 零起点参与者 | 尚无项目，但愿意探索 | 问题发现、小型任务、短周期共创和伙伴匹配 |

### 外部资源池

- 导师：学术导师、企业导师、行业专家；
- 企业：真实需求、企业命题、参访和合作机会；
- 投资人：行业视角、项目问诊和后续资本链接；
- 高校：学生、教师、双创组织和研究资源；
- 政府／机构：政策、园区、飞地、孵化和场地资源；
- 社区：开发者、创意工作者、自由职业者和数字游民。

### 当前待核实资源线索

- 苏州飞地／智能创新基地；
- 梦然、叶竞晗等潜在参与者；
- 应奇及其相关资源平台；
- 亚杰参与的小程序／固定页；
- “深圳贝斯／Base”“乌商”“拓车 AI 生态”“AXA”“其其真车队”等转写存疑专名。

## 五、空间与现场

| 空间 | 功能 | 典型使用 |
|---|---|---|
| 主会场 | 品牌亮相、大型分享、闭幕 | 启动仪式、主题活动、闭幕式 |
| Workshop 区 | 动手实践和小组共创 | Workshop、Hackathon、企业命题 |
| 小型交流区 | 深度讨论和资源匹配 | 圆桌、Office Hour、餐会、门诊 |
| 开发／共创区 | 持续项目推进 | 原型开发、项目迭代、团队协作 |
| 展览区 | 过程与成果展示 | 问题展、失败项目展、游园会、Showcase |
| 茶水社交区 | 非正式关系建立 | 破冰、自由交流、伙伴发现 |

### 现场保障

- 场地容量、动线、开放时间和噪音边界；
- 投影、音响、网络、电源、白板、展示板和桌椅；
- 签到、标识、主持、嘉宾接待、摄影摄像和应急物资；
- 开发／共创区在启动月内持续可用；
- 每场活动明确现场负责人、资源负责人和内容记录负责人。

## 六、品牌传播与内容记录

### 传播入口

- 品牌网站／固定页；
- 报名入口、合作入口和资源入口；
- 招募视频、活动预告和参与者故事；
- 个人身份、项目身份和贡献记录。

### 内容主线

1. 开场记录 Delta Space 从 0 到 1；
2. Step 1 记录问题如何被发现；
3. Step 2 记录伙伴、构建和资源如何发生；
4. Step 3 记录验证、失败和调整；
5. End 记录参与者成长、成果和下一次迭代。

## 七、团队、预算与数据

### 团队分工

- 总负责人：整体目标、节奏和关键决策；
- 品牌传播：Storyline、视觉、PR、网站和内容发布；
- 内容策划：命题、嘉宾、活动结构和阶段产出；
- 资源对接：企业、导师、投资人、高校和机构；
- 空间现场：场地、设备、动线、物料和接待；
- 报名运营：招募、筛选、签到、社群和参与者支持；
- 项目与留存：项目档案、反馈、协议、入驻和后续行动；
- 摄影记录：照片、视频、Vlog 和资料归档。

### 预算分类

- 场地与设备；
- 嘉宾与接待；
- 视觉、物料与网站；
- 餐饮与交通；
- 摄影摄像与内容制作；
- 应急预留。

### 数据与档案

- 报名、签到和参与者档案；
- 问题、命题、项目阶段和阶段产出；
- 导师、企业与资源匹配记录；
- 验证反馈、复盘结论和下一步；
- 协议、入驻、社群和持续活动台账。

## 八、衡量指标

| 维度 | 建议指标 |
|---|---|
| 触达与参与 | 有效报名、实际到场、持续参与比例 |
| 问题发现 | 问题／需求假设数量、具有证据的假设比例 |
| 共创构建 | 共创团队、原型、方案和阶段成果数量 |
| 资源链接 | 有效资源匹配、导师反馈、企业对接及后续行动数量 |
| 验证复盘 | 验证结论、复盘记录、继续／调整／停止判断 |
| 留存 | 核心留存、边缘留存和进入下一周期的项目数量 |
| 传播 | 内容产出、有效触达、参与者反馈和后续活动意愿 |

## 九、主要风险

- **品牌定位不清**：活动形式很多，但无法形成统一认知；
- **形式先行**：Hackathon、Workshop 等与真实命题脱节；
- **成熟度差异**：用一条开发主线要求所有项目同步推进；
- **资源承诺不足**：导师、企业或投资人只露出，不形成后续行动；
- **执行能力不足**：长周期空间、设备、现场和人员无法稳定支撑；
- **留存机制缺失**：活动结束后只有群聊，没有协议、入驻或持续内容；
- **转写信息误差**：专名、机构和网站未经确认便被当成准确线索。
