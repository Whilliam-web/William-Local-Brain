# Whilliam Local Brain

Whilliam 的本地 Obsidian 知识库，用于沉淀个人知识、项目成果、工作记录与可复用方法。

## 使用方式

1. 克隆仓库。
2. 用 Obsidian 打开本目录作为 Vault。
3. 从 `00收件箱` 处理新增信息；项目工作进入 `01三两的打工tasks`。
4. 开始协作前阅读 [AGENTS.md](AGENTS.md)。

## 目录

| 目录 | 用途 |
| --- | --- |
| `00收件箱` | 待处理信息 |
| `01三两的打工tasks` | 进行中的项目 |
| `02深耕领域` | 长期学习与领域知识 |
| `03只是玩耍` | 兴趣与实验内容 |
| `04百宝箱` | 可复用工具、方法与资料 |
| `05心法` | 判断框架与反思 |
| `06模版` | 可复用模板与规范 |
| `99系统` | 知识库说明、索引与协作规则 |

## 项目推进

需求确定 → 信息搜集与核验 → 方案 → 反馈 → 确认实施 → 验收与工作记录。

新产品项目先调研 GitHub 上的同类产品与开源实现，整理可借鉴点后再讨论方案。

## 协作与安全

- 仅提交确认后的正式成果。
- 草稿、日志、候选视觉稿与运行过程放在 `D:\AI Workspaces`。
- 不提交密码、Token、Cookie、私钥、个人敏感信息或未经确认的原始资料。
- 大规模移动、删除、重命名或覆盖内容前，先确认范围。
