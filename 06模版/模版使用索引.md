# 06模版

这里放可复用的工作模板和规范化格式。

模板不是为了让所有事情变得僵硬，而是为了让重复发生的事情有一个稳定起点。使用模板时，可以按具体任务删减，不需要每次都填满。

## 当前工作流

在大多数文件夹中新建空笔记时，Templater 会打开统一选择器：

- 📝 通用笔记
- 🚀 项目总览
- 🧾 工作记录
- 🔄 反馈复盘
- 📑 资料卡
- 🤖 智能体任务
- 🧰 百宝箱知识
- 🌱 深耕领域
- 🧠 心法判断
- 📦 归档
- 🏋️ 每周训练记录
- 📅 日历备忘录

其中 `00收件箱/日历备忘录` 由 Obsidian Daily Notes 单独处理，不触发 Templater 选择器。

## 模板体系结构

```text
06模版/
├── 文件夹模板/
│   └── 新建笔记选择器.md       ← 新建笔记时弹出所有模板选项
│
└── 具体任务的文件夹/
    ├── 通用笔记模板.md         ← 只生成基础 YAML 属性，不带标题和正文
    ├── 资料卡模板.md
    ├── 项目总览模板.md
    ├── 工作记录模板.md
    ├── 反馈复盘模板.md
    ├── 智能体任务模板.md
    ├── 百宝箱知识模板.md
    ├── 深耕领域模板.md
    ├── 心法判断模板.md
    ├── 归档模板.md
    ├── 每周训练记录模板.md
    └── 日历备忘录模板.md
```

## 使用原则

- 不确定笔记类型时，优先选“通用笔记”。
- 项目越复杂，越应该保留“目标、证据、风险、下一步”。
- 智能体任务先用“智能体任务模板”确定任务类型、正式项目路径、外部临时路径和最终成果。
- 草稿、预览、日志和候选成果保存在 `D:\AI Workspaces`；确认后的正式内容才写回知识库。
- 软件开发进入独立 Git 仓库，不在知识库根仓库创建 worktree。
- 模板用完后，如果发现某个字段长期没用，可以删；如果反复缺某个字段，可以补。
- 有价值的改动应反向更新模板本身。
